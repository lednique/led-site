# LEDNIQUE

Сайт-витрина LEDNIQUE: карточки, баннер, статьи, панель `/admin`.

- Языки: EN (Global) и RU. Определяется по системе, переключается в подвале.
- **Заявки без формы.** Блок «Заказать работу» открывает почтовую программу
  посетителя (`mailto:`) с готовой темой письма, рядом — ссылка на Telegram.
  Адрес и ник меняются в одном месте: `src/contacts.ts`. Сайт не собирает
  персональные данные, поэтому серверные переменные ботов и эндпоинт приёма
  заявок не нужны.
- **Две версии по стране посетителя** (`api/region.ts`, предпросмотр `?region=ru`,
  `?region=global`, сброс `?region=auto`). Отличие только в блоке «Соцсети»:
  международная версия показывает иконки, российская — текстовый ник Telegram
  (иконки Instagram и Facebook — символика Meta Platforms Inc., чья деятельность
  признана в РФ экстремистской и запрещена). Если страну определить не удалось,
  показывается российская версия.
- Карточки, баннер, кнопки и иконка вкладки живут в Supabase и синхронизируются сразу на всех устройствах. Без ключей сайт показывает встроенный демо-набор.
- Доступ к базе: чтение — всем, запись — только после входа в панель через
  Supabase Auth (политики RLS в `supabase/schema.sql`).
- Хостинг: Vercel (бесплатный план), заголовки безопасности — в `vercel.json`.
- Политика конфиденциальности встроена в сайт (`src/privacy.ts`, маршрут `/privacy`),
  постоянная ссылка на неё — вторая строка подвала.
